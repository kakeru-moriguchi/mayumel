## 4. デザインコンセプト

**「作品集のように、静かに。」**

料理本・作品集の誌面を下敷きに、装飾ではなく「写真・余白・罫線・書体」でデザインする。
カードや影、グラデーションに頼らず、写真の大きさと位置の差、余白の強弱でリズムを作る。
写真が入っていない段階でも写真枠そのものが誌面の要素として成立し、
実写真を置いた瞬間に完成度が一段上がる設計にする。

## 6. タイポグラフィ

- 欧文：**Cormorant Garamond**（ワードマーク・小さな英字ラベル・番号）
- 和文見出し・コピー：**Shippori Mincho**
- 和文本文：**Zen Kaku Gothic New**（16px / 行間 2）
- 大きな英語見出しはファーストビューの MayuMel のみ。各セクションは「小さな英字ラベル＋罫線＋和文見出し」
- すべて `next/font` で自己ホスト（CLS 対策）

## 7. 写真の配置方法

- 写真はすべて `src/content/images.ts` に登録（パス・alt・比率・仮ラベル）
- `public/images/…` に**登録されたファイル名で画像を置くだけで**写真枠が実写真に切り替わる（ビルド時に存在を判定）
- 仮枠は「Parfait Image」などのラベルと比率だけを表示。AI 生成の料理写真は使わない
- 推奨サイズは README 参照

## 9. 将来的な EC 拡張

- `src/config/site.ts` の `features.shop` を追加予定のフラグとして用意（ナビは `navigation` 配列に1行追加）
- 追加の想定構成：
  ```
  src/app/shop/page.tsx            商品一覧
  src/app/shop/[slug]/page.tsx     商品詳細
  src/app/cart/page.tsx            カート
  src/lib/commerce/                 商品取得・カート（Stripe / Shopify Storefront 等のアダプタ）
  src/content/products.ts           （または CMS）
  ```
- 既存ページは静的生成のみでサーバー状態を持たないため、EC を追加しても既存構造を変える必要はない
- 写真部品 `Photo` / ギャラリーは商品画像にも流用可能
- 今回は EC・決済・商品データは実装していない
